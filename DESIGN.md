# Stock Analyzer interface

A task-focused Angular 17 research workspace. Preserve the established teal identity and use the UI/UX Pro Max skill's verified guidance on clear hierarchy, contrast, table scrolling, accessible reactive forms and visible focus. The generated marketing-page patterns do not fit this application, so they are not applied.

Use a calm light canvas, white work surfaces, dark navy navigation, restrained teal actions and tabular financial numbers. Prioritize tables over decorative cards. Use plain labels: Screener, Companies, Price history, Bulk deals, Participants. Source dates are literal trading dates; fetched timestamps may use the reader's local timezone.

Tokens: background #f4f7f8; surface #ffffff; ink #17323f; muted #536873; accent #126c61; border #d9e3e7; focus #2679ad; danger #ac3030. Space on a 4/8px rhythm. Avoid fictional metrics, live-price badges, placeholder contacts and nonfunctional links.

Dialog forms retain failed submissions, announce errors, trap keyboard focus and return focus on close. Notes are shared in the original application and must be labeled accordingly. Financial charts use only actual available report rows, never generated points or forward-filled gaps. Respect reduced motion and test desktop, tablet and phone widths.
